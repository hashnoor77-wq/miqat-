# مِيقات — الساعة الزمانية والهدي النبوي

موقع عربي تفاعلي جاهز للنشر على **GitHub Pages** دون أي تثبيت أو إطار عمل.

## ماذا يفعل؟

- يعرض ساعة متحركة مرتبطة بتوقيت المدينة المحلي.
- يقسم الفترة بين **شروق الشمس وغروبها إلى 12 ساعة زمانية**، ويقسم الفترة بين **الغروب والفجر إلى 12 ساعة ليلية**، مع إظهار **الفجر إلى الشروق كفترة مستقلة**. هذا **تصميم هجين مقترح**، وليس تعريفًا فقهيًا ملزمًا للساعات.
- يعرض الساعة المدنية العادية بالثواني.
- يعرض **التاريخ الهجري وفق تقويم أم القرى**، ويبدل تاريخ اليوم الهجري عند الغروب.
- يبين أوقات الصلاة، الصلاة القادمة، الزمن المتبقي، منتصف الليل الشرعي، وبداية الثلث الأخير.
- يقترح أعمالًا مأثورة توافق فترة اليوم، مع **روابط للنصوص التي تثبتها**. لا يدعي وجود عبادة محددة لكل رقم من أرقام الساعة.
- يدعم 10 مدن وتغيير طريقة حساب المواقيت وتحديد موقع المستخدم (اختياري).

## طريقة النشر على GitHub Pages

1. أنشئ مستودعًا عامًا جديدًا في GitHub؛ مثلًا `miqat`.
2. ارفع الملفات الثلاثة `index.html` و`styles.css` و`app.js` **مباشرة إلى جذر المستودع** (يمكن رفع ملف `README.md` معها).
3. افتح **Settings → Pages** داخل المستودع.
4. عند **Build and deployment**، اختر **Deploy from a branch**؛ ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
5. سيكون الموقع على الرابط المعتاد `https://USERNAME.github.io/miqat/` بعد اكتمال عملية النشر.

لا تحتاج إلى `npm` أو Node.js أو خادم خاص.

## اختبار الموقع محليًا

يمكن فتح `index.html`، لكن يُفضل خادم محلي حتى تعمل ميزات الويب بصورة مستقرة:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## البيانات والدقة

- يتم جلب مواقيت الصلاة من [AlAdhan Prayer Times API](https://aladhan.com/prayer-times-api) عبر HTTPS مباشرة من المتصفح. لا يوجد مفتاح سري في المشروع.
- اختر **طريقة الحساب** المناسبة لمنطقتك من الإعدادات؛ قد تختلف المواقيت دقائق عن تقاويم الأوقاف والمساجد. لا تجعل الموقع بديلًا عن التقويم الرسمي عند الاختلاف.
- يُستخدم تقويم `islamic-umalqura` في واجهة `Intl.DateTimeFormat`. قد يختلف ظهور بداية الشهر الهجري بين الدول أو وفق الرؤية الشرعية؛ الموقع لا يثبت الأهلة.
- تُحفظ المواقيت التي تم جلبها محليًا في المتصفح، إلى جانب تفضيلات المستخدم. عند تعذّر جلب المواقيت دون نسخة محفوظة، **تظهر حالة خطأ واضحة بدل اختراع مواقيت**.
- خيار تحديد الموقع يطلب إذنًا من المتصفح؛ الإحداثيات تُرسل إلى مزود أوقات الصلاة عند الاستعلام، ولا يُشغّل هذا المشروع خادمًا لتجميع مواقع المستخدمين.
- يجري حساب منتصف الليل وبداية الثلث الأخير من **الغروب إلى الفجر الصادق**؛ ولا يُستخدم منتصف الليل المدني أو منتصف الفترة بين الغروب والشروق.
- الساعة الزمنية **ليست ساعة شرعية مفروضة**. نصوص السنن موثقة، لكن تصنيفها ضمن الفترات عمل توجيهي لتسهيل التذكّر وليس إثباتًا لبرنامج نبوي محدد لكل ساعة.
- في العرض، لا يعني وقت الأذان أن المستخدم صلى بالفعل؛ بطاقات الرواتب تذكر أنها تؤدى بعد الفريضة أو قبلها.

## بنية المشروع

- `index.html` — صفحة الموقع
- `styles.css` — تصميم RTL متجاوب
- `app.js` — تحديث الوقت، جلب المواقيت، الساعة والهدي النبوي

## تعديل العلامة أو التصميم

افتح `styles.css` وعدّل متغيرات الألوان في `:root`. لتعديل أو إضافة السنن ودلائلها راجع `entries` و`SOURCES` في `app.js`. راجع دائمًا نصوص الأحاديث قبل إضافة محتوى جديد.
